Methodology & transparency

Every discovery on this journal was produced by an automated or semi-automated run on Thabang's Windows machine. We publish the method next to the result so claims can be checked.

1 · What blocked, what worked

  • Nous web gateway DOWN for parts of these runs — web_search / web_extract returned "not available". Fallback was the terminal, which has direct internet, and the keyless ddgs search ring.
  • TikTok Slardar WAF blocks bare curl, yt-dlp, and the post-list API from this host. What worked: tiktok.com/oembed?url=… (returns title+author, no WAF) and a logged-in Chrome tab captured via computer_use AX-tree (real per-video like counts).
  • Gecho Bridge MCP is registered but its tools only load after a Hermes desktop-app restart — so some per-video metrics were captured manually via the AX-tree instead.

2 · arXiv digest (automated, stable)

The researcher-profile cron (research_digest.py, stdlib-only) queries arXiv's public API, writes a dated markdown file, and keeps a rolling index.md. Output is timestamp-free so a future monitor-mode hash could suppress unchanged runs. Runs daily at 06:30 SAST (Mon–Fri).

3 · Creator intelligence method

  1. Identify the handle from a paste / link.
  2. Confirm niche + bio from a WAF-clear mirror (tiktokv.com) or YouTube (yt-dlp, no WAF).
  3. Capture real engagement via oEmbed or a logged-in AX-tree snapshot.
  4. Reverse-engineer the hook/format from titles + pillar rotation.
  5. Record caveats explicitly (what was NOT retrievable).

4 · SA health-comms research

Burden facts sourced from Wikipedia "Health in South Africa" / "HIV/AIDS in South Africa" (2025) plus SAMRC/WHO context. The format was reverse-engineered from 32 real @medicalsciencefacts videos with live like counts. Scripts localise that format to SA burden and SA clinic CTAs; they are educational only and align with DoH test-and-treat / U=U messaging. Clinical claims in isiZulu variants are flagged for native review (noun-class agreement) before any paid/brand post.

5 · Provenance

Every page cites its source .md file. Raw sources are mirrored in /source on the public repo, so any reader can diff the published page against the original run output.

This page is itself a deliverable of the publishing run — written so the journal is citable, not just a blog.
