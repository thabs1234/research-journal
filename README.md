# research-journal

A free, public research publication by Thabang (South Africa).

Two streams:
- **Deep Research** — global / frontier studies (agentic-AI arXiv digest, creator intelligence on science & security short-form accounts).
- **South African Research** — work mapped onto SA's real burden & market (HIV/TB + NCD health-comms pilot packs, SA health-comms freelance pitch, ZA web/agency pricing).

## Why
Parallel research runs on this machine produce real discoveries. This journal publishes them — no paywall, full provenance.

## Structure
```
index.html                     # home — frames the two streams
deep-research.html             # global/frontier stream
south-african-research.html    # localised/applied stream
methodology.html               # how the runs were done (what blocked, what worked)
about.html                     # who/why/licence
assets/site.css                # shared stylesheet
source/                        # raw .md outputs from the original runs (provenance)
  deep/   (arxiv digest, ijep, medicalsciencefacts, byal)
  sa/     (MSF HIV/TB + NCD packs, pitch, calendar, ZA pricing)
```

## Hosting
Static site, served by GitHub Pages from `main`. No build step.

## Licence
Free to reuse with attribution. Health scripts are educational only — not medical advice.
